# Roadmap

Short-term:

- optional browser rendering for JavaScript-heavy sites;
- source adapters for common docs and landing-page structures;
- richer Korean editorial tokenization;
- benchmark fixtures for SaaS, editorial, developer tools, and commerce;
- JSON Schema for `voice.json`.
- a larger public pack library with regional editorial, luxury, developer,
  commerce, AI, and consumer-app categories.

Later:

- corpus mode for comparing several sites at once;
- GitHub Action wrapper;
- small hosted demo;
- integrations for Codex, Claude Code, Cursor, and Copilot instructions.

Non-goals:

- scraping private pages;
- imitating brands as if the output were official;
- implying affiliation with reference sources;
- treating source nouns, raw CTAs, or navigation labels as reusable style;
- rewarding copied paragraphs;
- requiring an LLM just to profile a page.
